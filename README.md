# 予備論文 添削ボード

予備試験・旧司法試験の論文答案を、合格答案の基準と比べて添削するための1ページのサイトです。

- **自動チェック**：字数、CBT換算のページ数、条文の摘示、数字つき事実の使用、問題文の事実の拾い率、問題文の書き写し、段落ごとの三段論法の目印
- **自己チェック**：合格答案と比べる8項目で、評価の目安（A圏〜D〜F圏）を出す
- **AI添削**：「プロンプトをコピー」してClaudeに貼る。または、自分のAnthropic APIキーを設定して、このページから直接添削する
- **合格答案の基準**：法務省の公式資料と、公開されている評価つき再現答案（R3〜R7、計117通）の分析
- **履歴**：添削をブラウザに保存。JSONで書き出し・読み込みができる

## GitHub Pages で公開する手順（10分）

1. **リポジトリを作る**
   - GitHub にログインして、右上の「＋」→「New repository」を押す。
   - Repository name に `yobi-tensaku` と入れる。
   - 「Public」を選ぶ（無料プランで Pages を使うには Public が必要）。
   - 「Create repository」を押す。
2. **ファイルを上げる**
   - できたページの「uploading an existing file」を押す。
   - `index.html` と `README.md` をドラッグして入れる。
   - 下の「Commit changes」を押す。
3. **Pages を有効にする**
   - リポジトリの「Settings」→ 左の「Pages」を開く。
   - 「Branch」で `main` と `/ (root)` を選んで「Save」を押す。
   - 1〜2分待つと、上に `https://（あなたのユーザー名）.github.io/yobi-tensaku/` が出る。そこを開けば使える。

更新するときは、新しい `index.html` を同じ手順で上げ直す（同じ名前なら上書きされる）。

## プライバシー

- 答案・問題文・履歴・APIキーは、**開いているブラウザの中（localStorage）にだけ**保存されます。GitHub には送られません。
- リポジトリは Public なので、**ページのコードは誰でも見られます**。答案は見られません。
- 基準には、再現答案の公開者の名前やアカウントは載せていません（一般化した特徴と法務省の資料だけ）。
- **AI添削（API）を使ったときだけ**、入力した答案と問題文が Anthropic に送られます。
- 共用のPCでは APIキーを保存しないでください。「設定」→「キーを削除」で消せます。

## AI添削について

- **APIキーなしで使う**：「プロンプトをコピー」→ Claude の新しいチャットに貼って送る。添削の形式と基準はプロンプトに入っている。
- **APIキーで使う**：console.anthropic.com でキーを発行し、「設定」に入れる。使った分だけ料金がかかる。モデルは `claude-sonnet-5`（標準）と `claude-opus-5`（高精度）を選べる。
- 自動チェックは語句の目印による機械判定で、中身の正しさは判定しません。推定評価は目安です。
